# PlanDiff

כלי להשוואת תכניות אדריכליות. בשלב הראשון אפשר להעלות שתי תכניות PDF בנות עמוד אחד, ליישר אותן, לבדוק את החפיפה ולשמור את היישור המאושר.

## הפעלה מקובץ ZIP

יש לחלץ את כל הקבצים ולפתוח טרמינל בתיקייה שבה נמצא `start.py`. נדרשים [Python 3.12](https://www.python.org/downloads/) ו־[Node.js 22 ומעלה](https://nodejs.org/), כולל npm.

**Windows (PowerShell)**

```powershell
py -3.12 start.py
```

**macOS / Linux**

```sh
python3.12 start.py
```

הפקודה מתקינה תלויות, בונה את ממשק המשתמש ומפעילה שרת מקומי. אחרי שמופיעה כתובת ההפעלה בטרמינל, פתחו בדפדפן את [PlanDiff](http://127.0.0.1:5180). השאירו את הטרמינל פתוח בזמן השימוש.

## התקנה לפיתוח

מתיקיית המאגר, עם Python 3.12 ו־Node.js 22 ומעלה:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
npm ci
```

## הפעלה לפיתוח

מפעילים את שני התהליכים בשני טרמינלים בתיקיית המאגר.

```sh
.venv/bin/python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```

```sh
npm run dev
```

פותחים את הכתובת ש־Vite מדפיס. בשרת ענן יש להוסיף `-- --host 0.0.0.0 --port 5173 --strictPort` לפקודת ההפעלה של Vite. בקשות API עוברות דרך Vite אל FastAPI בפורט 8000.

## בדיקות

```sh
.venv/bin/python -m pytest
npm run build
```

## יישור ושמירה

היישור מבוסס על התאמות SIFT ו־RANSAC ב־OpenCV. המטריצה ממפה פיקסלים מהמקור לתכנית השינויים. איכות היישור משקפת את שיעור ההתאמות שעברו סינון, את פיזורן ואת שגיאתן. כדאי לבדוק את החפיפה במסך היישור, במיוחד בסריקות באיכות נמוכה, בתכניות עם מעט חפיפה ובתכניות עם גאומטריה חוזרת. תיקון ידני משתמש בהזזה בפיקסלים, בסיבוב במעלות ובקנה מידה אחיד.

התמונות המרונדרות ומטריצת האישור נשמרות ב־SQLite בתיקיית `.plandiff/`. אפשר לבחור תיקייה אחרת באמצעות `PLANDIFF_DATA`. כתובת הפרויקט מאפשרת לפתוח אותו מחדש באותה התקנה. העיבוד מתבצע בשרת היישום ללא ספק חיצוני. בשלב זה ההתקנה מיועדת לעבודה מקומית או לסביבת פיתוח פרטית.

שלבים עתידיים כוללים זיהוי שינויים אדריכליים, הערות, אזהרות וייצוא. בדיקות השלב הראשון משתמשות בתכניות שנוצרו בקוד.
